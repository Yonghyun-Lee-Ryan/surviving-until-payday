# 디버그 패널 사용법

## 열기

- **F1** 또는 게임 화면 좌하단 **F1 Debug** 버튼
- Editor / Development Build 에서만 동작 (Release에서는 자동 제거)

## 주요 기능

| 구역 | 조작 |
|------|------|
| 날짜 | 입력 적용, D1/D7/D14/D15/D21/D30 점프 |
| 현금 | ±100k / ±500k / 0원 / 부자 500만 |
| 능력치 | 일괄 적용, 위기·안정·해고위기 프리셋 |
| 시드 | 재적용 후 당일 사건 재추첨 |
| 사건/엔딩 | 필터(id/title) + 강제 |
| 실패 | 드롭다운(파산·입원·번아웃·해고) + 선택 실패 |
| 플래그 | owesDebt 등 토글 / 전체 클리어 |
| 상태 로그 | Console + 상태줄에 Day/Cash/Flags 덤프 |

## 씬 재생성 (선택)

기존 씬 패널이 구버전이면 Play 시 런타임으로 UI를 재구성한다.  
에디터에서 영구 반영하려면:

`Tools → Surviving Until Payday → Setup Debug Panel (Unit 11)`
