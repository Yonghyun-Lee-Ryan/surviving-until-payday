# R-QA-06 UX 체크리스트 (수동 Play)

Unity: `D:\Unity\Editor\6000.5.4f1`  
에디터 자동: `Tools → Surviving Until Payday → Run UX Checklist (R-QA-06)`  
리포트: `Logs/rqa06_ux_checklist_*.txt`

상점·IAP는 사용하지 않는다.

## 자동으로 이미 확인한 것

- 튜토리얼 5스텝에 **실패해도 OK** · **안전만 고르면 엔딩이 비슷** (G9)
- 결과 화면 **엔딩 기록 복사** (클립보드, 외부 SDK 없음) (G6)
- 설정 **선택 미리보기** 토글 (schema 4, 기본 OFF · 설정에서 켜야 표시) (G10)
- 광고 버튼은 숨기지 않고 **한글 비활성 사유**(한도/쿨다운/미준비)
- HUD `SetAsLastSibling` 이후 Result/Weekly를 다시 올림 (`UiModalLayer`)
- Editor/Development만 DebugPanel 유지, Release 소스는 `Destroy(gameObject)`

## 수동 Play 순서

1. **저장 초기화(선택)**  
   첫 실행을 보려면 설정 → 저장 데이터 초기화 후 에디터 Play.
2. **스플래시 → 동의**  
   Bootstrap → 개인정보 동의 패널이 HUD/다른 UI 위에 보인다. 동의 후 메인.
3. **튜토리얼**  
   5스텝. 「실패해도 됩니다」·안전만 고르기 함정·선택 미리보기 안내. **건너뛰기** 가능. 완료 후 재접속 시 안 나옴.
4. **회차 시작**  
   직업 선택 후 Game. 기본은 선택지 문구만. 설정에서 「선택 미리보기」를 켜면 `(현금↑ …)`가 붙는다.
5. **선택 피드백**  
   결과 팝업: 숫자 변화 + 드라마 한 줄. 팝업이 **상단 HUD를 가리지 않고**, HUD가 팝업을 가리지도 않는다.
6. **7일 주간결산**  
   7일 종료 후 주간결산이 HUD **위**. 위험이 없으면 안전-only 힌트, 있으면 “실패해도 다음 주…”.
7. **광고 버튼**  
   한도 소진·쿨다운 시 버튼은 보이고 라벨이 사유. 클릭 불가면 진행은 「다음 날」로 가능.
8. **실패 또는 성공**  
   Result 씬: 「다음엔 이렇게」 팁(실패해도 경험치/도감). **엔딩 기록 복사** → 붙여넣기에 제목·일수·해시태그.
9. **이어하기**  
   메인 → 이어하기. 튜토리얼 재표시 없음. 저장 날이 이어진다.
10. **Release DebugPanel**  
    에디터 Play에서는 F1 Debug가 있다. **Release 플레이어 빌드**에서는 Debug 버튼/패널이 없어야 한다.

## 회귀 포인트

- Game 씬에서 HUD 레이아웃을 다시 적용해도(해상도·설정 복귀) 열린 결과/주간결산이 HUD 뒤로 내려가면 실패.
- 광고 쿼터 0일 때 버튼을 숨기면 실패(사유를 보여야 함).
