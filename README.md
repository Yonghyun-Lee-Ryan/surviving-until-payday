## 2. 게임 핵심 콘셉트

플레이어는 월급을 받은 직장인이 되어 30일 동안 발생하는 소비, 직장, 건강, 인간관계 사건에 대응한다.

매일 하나의 사건이 등장하며, 플레이어는 세 가지 선택지 중 하나를 선택한다. 선택에 따라 돈, 건강, 스트레스, 행복도, 회사 평가가 변한다.

30일째까지 생존하면 월급이 입금되고 한 회차가 종료된다.

### 핵심 문장

> 월급은 들어왔지만, 다음 월급날까지 살아남는 것은 당신의 선택에 달려 있다.

### 재미의 중심

* 제한된 돈으로 무엇을 포기할지 결정하는 재미
* 예상하지 못한 사건이 연속으로 발생하는 긴장감
* 위험한 선택에서 큰 보상을 얻는 도박성
* 이전 실패를 바탕으로 다음 회차를 더 잘 운영하는 성장감
* 직장인이라면 공감할 수 있는 현실적인 사건과 유머

## 3. 핵심 게임 루프

```text
월급 수령
→ 직업·특성 선택
→ 하루 시작
→ 고정 지출 또는 무작위 사건 발생
→ 세 가지 행동 중 하나 선택
→ 능력치 및 보유 현금 변화
→ 하루 결산
→ 다음 날 진행
→ 7일 단위 주간 정산
→ 30일까지 생존
→ 엔딩 및 경험치 획득
→ 새로운 직업·특성·사건 해금
→ 다음 회차 시작
```

### 플레이 감정 흐름

```text
여유
→ 예상치 못한 소비
→ 불안
→ 절약 또는 위험한 선택
→ 잠시 회복
→ 더 큰 사건
→ 월급날 직전의 극한 상황
→ 생존 또는 파산
```

## 5. 핵심 능력치

| 능력치   |    범위 | 실패 조건    | 설명              |
| ----- | ----: | -------- | --------------- |
| 현금    | 제한 없음 | 0원 미만    | 생활비와 고정비 결제에 사용 |
| 건강    | 0~100 | 0 이하     | 병원비와 업무 수행에 영향  |
| 스트레스  | 0~100 | 100 이상   | 번아웃 위험          |
| 행복도   | 0~100 | 직접 실패 없음 | 엔딩과 이벤트 선택에 영향  |
| 회사 평가 | 0~100 | 0 이하     | 해고 위험           |

### 능력치 설계 원칙

어떤 선택도 완전히 좋은 결과만 제공하지 않는다.

예시:

* 야근하기: 회사 평가 +10, 스트레스 +15, 건강 -5
* 회식 참석하기: 현금 -40,000원, 회사 평가 +8, 스트레스 +5
* 회식 거절하기: 현금 변화 없음, 회사 평가 -5, 행복도 +3
* 배달 음식 주문하기: 현금 -25,000원, 행복도 +8, 건강 -2
* 집에서 요리하기: 현금 -8,000원, 스트레스 +2, 건강 +3

## 6. 날짜 시스템

한 회차는 총 30일이다.

### 날짜별 구성

| 날짜     | 주요 특징            |
| ------ | ---------------- |
| 1일     | 월급 입금 및 시작       |
| 2~6일   | 일반 사건            |
| 7일     | 주간 결산            |
| 8~13일  | 사건 난도 증가         |
| 14일    | 두 번째 주간 결산       |
| 15일    | 카드 대금 또는 고정비 이벤트 |
| 21일    | 세 번째 주간 결산       |
| 22~27일 | 고난도 사건 증가        |
| 28~29일 | 월급날 직전 위기 사건     |
| 30일    | 최종 결산 및 월급 입금    |

### 주말 규칙

토요일과 일요일에는 직장 사건 발생 확률이 감소하고 다음 사건이 증가한다.

* 친구 약속
* 데이트
* 가족 행사
* 병원 방문
* 쇼핑
* 부업
* 휴식

## 10. 선택지 설계 규칙

각 사건은 세 가지 성격의 선택지를 제공한다.

1. 안전한 선택
   비용 또는 손실이 확정적이지만 위험이 낮다.

2. 절약 선택
   돈을 아낄 수 있지만 다른 능력치가 감소한다.

3. 위험 선택
   확률에 따라 큰 이득 또는 손해가 발생한다.

### 확률형 결과 예시

```text
사설 수리점 이용

70%: 정상 수리
20%: 며칠 후 다시 고장
10%: 데이터 손실
```

확률형 결과는 실제 현금 결제가 아닌 게임 내부 선택에만 적용한다.

## 11. 난도 시스템

날짜가 진행될수록 사건의 평균 손실이 증가한다.

```text
사건 최종 난도
= 사건 기본 난도
× 날짜 보정값
× 플레이어 현재 상태 보정값
```

### 날짜 보정값 예시

| 기간     |  보정값 |
| ------ | ---: |
| 1~7일   |  1.0 |
| 8~14일  |  1.1 |
| 15~21일 |  1.2 |
| 22~27일 | 1.35 |
| 28~30일 |  1.5 |

단, 플레이어를 강제로 실패시키지 않도록 회복 사건도 일정 비율로 등장시킨다.

### 사건 덱 구성 권장 비율

| 유형        |  비율 |
| --------- | --: |
| 일반 손실 사건  | 35% |
| 선택적 소비 사건 | 20% |
| 회복 사건     | 15% |
| 기회·부업 사건  | 15% |
| 확률형 위험 사건 | 10% |
| 특수 사건     |  5% |

## 12. 실패 조건

### 파산 엔딩

현금이 0원 미만이 되었고 대체 결제 수단도 없는 경우.

### 번아웃 엔딩

스트레스가 100에 도달한 경우.

### 병원 입원 엔딩

건강이 0에 도달한 경우.

### 해고 엔딩

회사 평가가 0에 도달한 경우.

## 13. 성공 및 엔딩

30일까지 생존하면 최종 능력치에 따라 엔딩을 결정한다.

| 엔딩        | 조건                   |
| --------- | -------------------- |
| 통장 잔고의 제왕 | 현금 1,000,000원 이상     |
| 건강한 직장인   | 건강 70 이상, 스트레스 40 이하 |
| 승진 후보     | 회사 평가 80 이상          |
| 행복한 소비왕   | 행복도 80 이상            |
| 겨우 살아남았다  | 모든 능력치가 낮지만 생존       |
| 카드 돌려막기   | 빚을 사용해 생존            |
| 퇴사 준비 완료  | 현금이 충분하고 회사 평가가 낮음   |
| 인생은 한방    | 투자 이벤트에서 큰 성공        |

엔딩은 도감에 저장된다.

## 14. 메타 성장

회차 종료 시 `인생 경험치`를 획득한다.

### 경험치 획득 기준

* 생존 날짜
* 발견한 새로운 사건
* 해금한 엔딩
* 남은 현금
* 완료한 도전과제
* 광고 시청을 통한 보상 2배

### 해금 항목

* 새로운 직업
* 시작 특성
* 새로운 사건
* 새로운 엔딩
* 캐릭터 외형
* 방 꾸미기 요소

### 직업 확장

| 직업        | 특징               |
| --------- | ---------------- |
| 중소기업 신입사원 | 표준 난도            |
| 공무원 준비생   | 낮은 수입, 낮은 직장 사건  |
| 프리랜서      | 수입 변동이 큼         |
| 대학원생      | 낮은 현금, 연구 이벤트    |
| 스타트업 개발자  | 높은 스트레스, 스톡옵션 사건 |
| 대기업 사원    | 높은 월급, 높은 고정 지출  |
| 자영업자      | 매출과 비용이 매일 변동    |

MVP에서는 중소기업 신입사원만 구현한다.

| 체력왕   | 건강 최대치 +20              |
| 눈치왕   | 회사 평가 감소량 20% 감소        |
| 긍정왕   | 행복도 감소량 20% 감소          |
| 야근전문가 | 야근 스트레스 감소              |

## 16. 광고 수익화

광고는 게임 흐름을 방해하지 않고 선택 가능한 보상으로 사용한다.

### 보상형 광고

| 시점         | 보상             | 제한     |
| ---------- | -------------- | ------ |
| 사건 선택 전    | 선택지 새로고침       | 회차당 2회 |
| 위험 선택 실패 후 | 결과 한 번 재시도     | 회차당 1회 |
| 파산 직전      | 긴급 대출 100,000원 | 회차당 1회 |
| 하루 종료      | 부업 수익 30,000원  | 하루 1회  |
| 회차 종료      | 인생 경험치 2배      | 회차당 1회 |
| 무료 상점      | 특성 조각 지급       | 하루 3회  |

### 전면 광고

* 첫 세 회차에서는 노출하지 않는다.
* 게임 도중에는 노출하지 않는다.
* 결과 화면에서 메인 메뉴로 이동할 때만 노출한다.
* 기본적으로 2~3회차당 한 번 노출한다.
* 보상형 광고를 본 직후에는 노출하지 않는다.

### 광고 제거 상품

광고 제거 상품은 전면 광고만 제거한다.

보상형 광고는 사용자가 원하는 경우 계속 선택할 수 있다.

## 25. 핵심 성공 조건

이 게임은 사건의 양보다 선택의 고민이 중요하다.

> 돈을 아낄 것인가, 건강을 지킬 것인가, 회사에서 살아남을 것인가?

각 선택은 결과를 예측할 수 있어야 하지만, 언제나 명확한 정답이 있어서는 안 된다.
